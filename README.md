Entry for the make.fun bounty "Write the best poem about agency" (agency-poem-01, $250). The program writes a single poem to /output/entry.txt — the user's own agency poem, "I AM THE AUTHOR OF MY OWN CHOICES", trimmed to fit the 1,000-character limit by dropping only its title line (984 characters). It runs on Python 3.13 with the standard library only, needs no network, and writes byte-identical output on every run.
